# ePayco v17.0
 
## Installation

Pasos:

- Agregar el directorio clonado de este repositorio a la ruta de addons de la instancia de Odoo. 
- Ir a la base de datos y actualizar la lista de aplicaciones.
- Instalar el modulo payment_epayco.
- [agregar directamente desde las aplicaciones de odoo](https://apps.odoo.com/apps/modules/browse?search=epayco)

## Configuration

- Ir a Sitio web / Configuración / Proveedores de pago.
- Seleccionar ePayco
- Implementar Credenciales
- Ir a Configuración -> FORMULARIO DE PAGO -> Permitir método de pago -> epayco
- Activar el metodo de pago
